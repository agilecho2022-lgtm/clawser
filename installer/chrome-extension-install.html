安装 Clawser Browser Relay

Clawser 已经安装好。Chrome 插件需要你手动加载一次，这是 Chrome 的安全限制。

1. 打开 Chrome 扩展管理页

在 Chrome 地址栏打开 chrome://extensions。 如果链接没有响应，请手动复制 chrome://extensions 到地址栏。

2. 开启开发者模式并加载插件目录

  1. 打开右上角 Developer mode / 开发者模式。
  2. 点击 Load unpacked / 加载已解压的扩展程序。
  3. 选择下面这个安装目录里的 chrome-extension 文件夹。
chrome-extension

3. 在插件设置页点击 Save

插件安装后会打开 Clawser Browser Relay 设置页。 保持端口为 18792，点击 Save。

如果设置页没有自动打开，可以在扩展详情页点击 Extension options / 扩展程序选项。

4. 从托盘启动并连接当前标签页

  1. 点击系统托盘或菜单栏里的 Clawser。
  2. 如果菜单显示 Start Clawser，点击它并等待状态变成 On。如果菜单显示 Stop Clawser，说明 relay 已经在运行。
  3. 打开要控制的网页，点击 Chrome 工具栏里的 Clawser Browser Relay 图标。
  4. 徽标显示 ON 后，托盘状态会变成 Attached。

以后不用重复加载插件。需要重新查看说明时，可以打开安装目录里的 chrome-extension-install.html。
